02 — Research Gap

Why 1D Fusion is Insufficient

Sequence-level fusion treats each residue independently. PPI binding sites are determined by surface patches — clusters of residues defined by their 3D geometric proximity, not sequence order.

🔬
Biophysical Rationale
Prior work (DHEG, Briefings in Bioinformatics 2026) showed that naive PLM concatenation or replacement of PSSM/HMM features reduces MCC to as low as 0.086. The unresolved question was whether a structure-conditioned attention mechanism could enable PLM embeddings to contribute a genuine complementary signal without dominating classical evolutionary features.
✅
Our Solution: 3D-Constrained Attention Routing
By constructing an attention mask derived from the 14Å protein contact graph, each residue's classical query vector (from PSSM/HMM) can only attend to the PLM key/value vectors of its structural neighbors. This injects geometry into the fusion step before any GNN message passing occurs.

Formal Derivation

For each residue i in a protein sequence of length L, we define projections, a 3D spatial mask, and a structure-constrained attention output.

qi = LayerNorm( Wq · xiclassical + bq ) ∈ ℝd
ki = vi = LayerNorm( Wk · xiplm + bk ) ∈ ℝd
Step 2 · 3D Spatial Additive Attention Mask
Let ε = { (i,j) | dist(i, j) ≤ 14Å } (protein contact graph)

Mi,j = { 0.0 if i = j or (i,j) ∈ ε

Step 3 · Masked Attention & Residual Fusion
A = Softmax( ( Q · Kᵀ / √d ) + M ) ∈ ℝL×L
fi = LayerNorm( qi + (A · V)i ) ∈ ℝd

node_featuresi = concat( fi, DSSPi, AFi ) ∈ ℝ149
04 — Architecture

End-to-End Feature Pipeline

The 3D-SCA module sits at the boundary between raw feature extraction and GNN propagation, acting as a structure-aware adapter that translates PLM biophysical grammar into the GNN's graph topology.

🧬
Classical Evolutionary Features
Per-residue PSSM (20d) and HMM profile (20d) are concatenated to form a 40-dimensional evolutionary fingerprint encoding sequence conservation across homologous families.
xiclassical ∈ ℝ⁴⁰ → Wq → qi ∈ ℝ¹²⁸
🤖
ESM-2 PLM Embeddings
Pre-extracted per-residue embeddings from ESM-2 650M (facebook/esm2_t33_650M_UR50D), cached on disk as float16 .npy files. These encode implicit structural and biophysical co-evolution signals learned from 250M protein sequences.
xiplm ∈ ℝ¹²⁸⁰ → Wk → ki, vi ∈ ℝ¹²⁸
📐
3D Spatial Mask Construction
The protein's 3D Cα coordinate graph (14Å cutoff) is converted into a binary neighborhood adjacency. An additive float mask M is built such that only spatial neighbors (and self) receive zero masking; all other pairs receive −10⁹ to force softmax weights to zero.
M ∈ ℝᴸˣᴸ, M[edges] = 0.0, M[others] = −1e9
🧩
Structure-Gated Cross-Attention
Classical query vectors attend to PLM key/value vectors only within their 3D neighborhood. This constrains knowledge transfer to spatially co-localized patches, reflecting how cooperative binding surface patches actually function in protein biology.
fi = LayerNorm( qi + Softmax(QKᵀ/√d + M) · V )
⚡
GNN Propagation (EGNN + GraphTransformer)
The fused 128d representation is concatenated with DSSP (14d) and atomic features (7d), forming a 149d node feature vector. This is passed through 10 EGNN layers and 4 GraphTransformer layers. Outputs are averaged and classified via a 2-class linear head.
node_i = cat(fi, dsspi, afi) ∈ ℝ¹⁴⁹ → EGNN → GT → logits
05 — Training Stabilization

Numerical Stability Fixes

Combining multihead attention projections with equivariant GNN coordinate updates creates two critical failure modes, both diagnosed and resolved during empirical testing across the full 334-protein training dataset.

⚠️
Failure Mode 1 — EGNN Coordinate Explosion
In proteins with L > 400 residues, the internal coordinate update Δx accumulated exponentially across 10 EGNN layers, causing loss values to jump from 0.35 to 549.07 within 5 training steps. Root cause: unbounded coord_diff vectors in the equivariant message passing.

⚠️
Failure Mode 2 — Attention Weight Saturation (LR=1e-3)
The 1280→128 projection layers (PLM stream) and the three Q/K/V projection matrices of MultiheadAttention together contain approximately 4.3M parameters. Optimizing these at the standard GNN learning rate of 1e-3 caused optimizer overshoot, with gradient norms reaching 2520 before clipping. Reducing to 1e-4 reduced average per-step gradient norm to 2–8, fully eliminating the explosion.

06 — Key Implementation

Spatial Mask Forward Pass

Python · fusion_module.py
elif self.fusion_mode == 'cross_attn':
    L = c_proj.size(0)
    device = c_proj.device

    # Build 3D spatial additive attention mask
    # -1e9 is added to non-neighbor logits → softmax(x + -1e9) ≈ 0
    attn_mask = torch.full((L, L), -1e9, dtype=c_proj.dtype, device=device)

    # Residue i can always attend to itself
    attn_mask.fill_diagonal_(0.0)

    if edges is not None and edges.numel() > 0:
        # Allow 14Å spatial neighbors to attend bidirectionally
        attn_mask[edges[0], edges[1]] = 0.0
        attn_mask[edges[1], edges[0]] = 0.0

    # Pack as (1, L, d) batch-first for nn.MultiheadAttention
    q  = c_proj.unsqueeze(0)
    kv = p_proj.unsqueeze(0)

    attn_output, _ = self.cross_attention(q, kv, kv, attn_mask=attn_mask)
    attn_output = attn_output.squeeze(0)

    # Residual connection + LayerNorm for training stability
    fused_i = self.post_attn_ln(c_proj + attn_output)
